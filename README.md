# Juegos de Gabriel Vidal

Simulaciones educativas. Cada juego es una página web autónoma (HTML, CSS y JavaScript en un solo archivo) y se publica con [GitHub Pages](https://gvidal5.github.io/juegos/) desde la raíz de la rama `main`.

**Portal:** https://gvidal5.github.io/juegos/

## Juegos

| Juego | Módulo | Enlace |
| --- | --- | --- |
| TORNILLÖN · Simulación de atención por chat | Digitalización Aplicada al Sistema Productivo · 2º Gestión Administrativa | [tornillon/](tornillon/) |

TORNILLÖN incluye dos partidas tipo WhatsApp: una en el papel de cliente (`cliente.html`) y otra en el de comercial (`comercial.html`). La empresa, sus productos y sus datos son ficticios.
